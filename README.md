# 🚗 Plate Hunter

A licence plate spotting game. When you see a plate from a US state (or D.C.), type the state into the search bar and press **Enter** to add it to your collection. Try to collect all 51!

## How to play
- Open `index.html` in any web browser (no install needed).
- Type a state name or its 2-letter code (e.g. `Ohio` or `OH`). Use ↑/↓ to pick a suggestion, then **Enter** or click.
- Check the **Still Missing** tab to see what's left (you can click a missing plate to add it).
- Hover a plate and click ✕ to remove it if you made a mistake.
- Your progress is saved in your browser automatically.
